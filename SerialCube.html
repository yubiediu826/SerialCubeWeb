更新日志
v6.5 版本 · 26/8/5
  • 仪表盘卡片改用 flex 布局，固定 220px 宽，1 card 居左不拉满，间距统一协调。
  • 命令 tab 左右导航按钮合并到最右侧，支持鼠标滚轮水平滚动。
  • 告警改用 toast 浮层（5s 自动消失）+ 右上角"通知"按钮查看最近 20 条历史，支持单条删除和清空。
  • toast 统一 SVG icon + 中文标签（信息/成功/警告/错误），色盲友好。
  • 重要弹窗（卡片详情/协议编辑器/卡片配置）保持居中显示，不被系统菜单的弹窗位置影响。
  • 卡片编辑模式 HTML 层面切换图标：普通模式右上角无任何 icon，编辑模式显示铅笔编辑 + 垃圾桶删除（透明 SVG 无底色）。
  • 删除按钮图标改用通用垃圾桶 SVG，所有字符图标（ⓘ✓⚠✕/⇄↗✎🔒/×）全部换 SVG。
  • sparkline 移除 max 虚线和"max"文字标注，简化图表显示。
  • 卡片底部范围文本加"范围"前缀（"2.8-4.2V" → "范围 2.8-4.2V"），含义更明确。
  • 列表卡片数值字号放大（22→28px），删除内部 cmd·field 冗余文本。
  • 系统菜单支持弹窗位置 4 方位（tr/tl/br/bl），仅影响 toast 提示位置。
v1.5 版本 · 26/7/9
  • "自动硬件流控"更名为"RTS/CTS 流控"，名称更准确。
  • 重构 TX/RX 收发与换行符显示逻辑，优化监视器渲染与事件处理。
v1.4 版本 · 26/7/4
  • 优化页面配色与扁平化设计，浅色/深色模式分离。
  • 优化预设发送交互逻辑，通过开关控制全局快捷键的预设发送。
  • 新增解析配置帮助提示，支持悬浮查看规则说明。
v1.3 版本 · 26/6/30
  • 新增柱状图，支持通道选择、纵轴缩放与自动量程。
  • name 标签匹配逻辑改为后缀数字匹配（name0↔int0），规则格式更灵活。
  • 预设发送支持单字符快捷键，按下即发；自动全选，替换即生效。
  • 修复 GitHub 历史版本仓库，优化离线版本使用体验。
  • 优化紧凑显示模式、布局间距与各面板一致性。
  • 优化通道交互、图框渲染、频域图通道筛选与 name 动态字段跟踪。
  • 优化时间线回放、配置导入导出的图框状态同步与持久化。
  • 优化模板解析、发送数据过滤与复选框样式统一。
v1.2 版本 · 26/6/11
  • 支持定时、触发和预设发送在十六进制模式下保留原始字节，统一发送匹配与显示逻辑。
  • 支持高级发送展开区高度拖动调整及各模块拖拽排序。
  • 支持预设发送添加备注描述，监视器中显示发送与匹配状态标识。
  • 优化十六进制结构解析，支持间隔符占位和帧尾留空的宽匹配逻辑。
  • 优化实时解析结果展示，支持横向滚动、展开和折叠。
  • 修正连接状态下修改串口参数未立即生效的问题。
  • 新增全局配置导入导出与还原，统一保存设备、发送、解析及图框配置。
v1.1 版本 · 26/5/30
  • 支持设置、输入状态在退出后自动保存，下次加载时恢复使用。
  • 支持离线版本的下载和离线版本使用，并支持离线状态识别。
  • 优化视觉效果，包括弹窗、下拉状态和窄屏悬浮窗的模糊背景。
  • 新增关于弹窗、版本日志、工具手册、GitHub 和问题反馈入口。
v1.0 版本 · 26/5/24
  • 支持串口监视、设备连接管理、VID/PID 显示、串口参数配置及硬件流控与信号控制。
  • 支持深浅主题自动切换及宽屏/窄屏两种布局策略。
  • 加入自动重连机制，设备插拔或连接丢失后可尝试恢复。
  • 加入失焦自动断连机制，窗口失焦时释放串口，恢复焦点后继续使用。
  • 支持图形解析，含文本解析、十六进制结构解析、自动识别规则及实时结果展示。
  • 支持时域图与频域图绘制，可绑定解析通道并调整视图范围与量程策略。
  • 支持时间线系统，含实时冻结、录制归档、回放、导入导出与解析配置复用。
  • 时间线支持导入/导出 BIN/TXT/CSV 原始文件及 TXT/CSV 解析结果。
  • 支持手动、定时、触发和预设发送等串口调试工作流。
