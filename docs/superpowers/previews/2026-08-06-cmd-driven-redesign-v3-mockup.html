关键设计决策 (V3 final)

  • 方案层 = 极简 3 项(命名 + kind + CRC),不存 fields / dataFields。
  • 帧字段 来自 kind 模板,锁死不可改 (新建命令/方案详情都不需要展示, 帧预览自动显示)。
  • 数据字段 是命令级,每个命令自己管字段池 + 选子集(在 Step 2 modal 段 2 配置)。
  • 方案编辑器 = 顶层入口,方案列表 + 选中方案下方的命令列表。
  • 新建方案 = 2 步向导: Step 1 命名+kind+CRC → Step 2 自动跳到新建命令 → 完成首命令。
  • 方案详情 = 极简 3 段(基础 + 该方案下的命令 + 同步提示),不展示 fields/dataFields。
  • 改协议字段 = 改方案 → 弹确认"将影响 N 个命令, 确认同步?"。
  • 仪表盘 按方案分组 (kind 标签 + 颜色条,跟 v2 一致)。
  • 全部 SVG icon,零字符图标/emoji(跟 v4.9.3 实际代码一致)。
