P0-5 区域 5 — 删除确认 (方案 / 命令 / 字段)

删方案
将删除方案 BMS TLV 方案:
  • → 4 个命令 (读取 1#/2# 电压, 1#/2# ack)
  • → 4 个仪表盘卡片 (卡片 1-4)
  • → 6 个已存储配置字段 (charge_v / cell_1_v / etc.)
操作不可撤销 · 建议先导出此方案备份
删命令
将删除命令 读取 1# 电压:
  • → 仪表盘卡片 1 (charge_v) 同步删除
  • → 数据字段 charge_v (其他命令没用) 同步删除
  • → pair trigger 配置 (1# ack) 失效
操作不可撤销
删字段
将删除字段 battery_temp:
  • → 仪表盘字段绑定失效
  • → 当前命令 (1 个) 不再用此字段
仅本命令用,影响小
