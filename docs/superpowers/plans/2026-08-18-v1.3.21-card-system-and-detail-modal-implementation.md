# v1.3.21 卡片系统 & 详情弹窗 实施 Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 SerialCube 仪表盘实施"全协议卡片系统 + 详情弹窗" — 11 卡片类型 + 8 弹窗模式 + 1×1/2×1 卡片尺寸体系 + chart-logs 弹窗复用 TREND。

**Architecture:**
- 现有 4 卡片 (trend/set/control/pair) + v1.3.20 新 2 卡片 (bit/bit_set) = 6 卡片，扩展到 11 卡片
- 8 种弹窗模式：chart-logs (复用 TREND) + bit-history + bit-editor + big-metric + array-matrix + text-detail + log-table + wizard-flow
- 卡片尺寸：1×1 (220×198) 默认 + 2×1 (440×198) 横向 2 倍
- 5 新弹窗模式分 2 批实施（第 2 批：数据类 BIG/ARRAY，第 3 批：流程类 STRING/LOG/WIZARD）

**Tech Stack:** HTML/CSS/Vanilla JS（单文件 SerialCube.html ~31K 行）+ ECharts（CDN，按需加载）+ Web Serial API

**Spec 文档:** `docs/superpowers/specs/2026-08-18-card-system-and-detail-modal-design.md`
**Preview HTML:** `docs/design/v1.3.21-card-system-and-detail-modal-overview.html`
