3引导流程 4 步 — 新手走一遍: 协议 → 命令 → 卡片 → 完成

第 1 步
配协议
选/新建协议, 调帧模板 (header/addr/length/data/crc/tail)。
8 种 kind 可选 或自己拼。
第 2 步
加命令
在当前协议下加 N 条命令 (0x01 读, 0x10 写, 0x90 响应…)。每条命令自带数据字段。
第 3 步
配卡片
选命令的某个字段做卡片 (TREND 趋势 / PAIR 对比), 设单位、范围、精度。
第 4 步
告警自动
卡片 range 自动派生告警规则, 无需手动。关掉 modal 即可看到数据流。

4自定义协议 3 路径 — 覆盖 95% 场景, 0-1-2 行代码

90%
PATH A
选个 kind 自由编辑
最像你协议的那个 kind 当起点, 在 wizard 第 3 步把字段全删了重排。
  • 新建协议 → 选最接近的 kind
  • 第 3 步: 删字段 / 改类型 / 拖排序
  • 保存即用, 不需要改代码
代码改动: 0 行
PATH B
Custom 空白 kind
跟任何预设 kind 都不像的协议, 用纯空白模板从零开始拼。
  • 新建协议 → 选 Custom
  • 第 3 步: 手动添加 header/cmd/data/crc 等字段
  • 数据字段编码规则全自己定
代码改动: ~1 行 (kind 列表加一项)
PATH C
导入厂商协议 JSON
厂商/社区提供协议定义 JSON 文件, 一键导入复用。
  • 「导入/导出」tab → 选协议 JSON 文件
  • 解析 + 校验, 提示导入成功
  • 协议出现在协议列表, 可二次编辑
代码改动: 0 行 (复用 Tab 4 导入逻辑)
