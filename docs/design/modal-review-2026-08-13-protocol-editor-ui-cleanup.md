## 1. 必要性

### 协议条 (`#dh-dash-proto-bar`)
- [❌] **"未连接"** (`#dh-dash-proto-port`)：与左侧连接管理面板的"连接设备 | 当前未连接"**功能重复**
- [❌] **"设置值" 按钮** (`#dh-dash-settings-btn`)：未连接时 disabled (opacity 0.4)，**永远不可点**——占位
- [❌] **"选择协议" 按钮** (`#dh-dash-proto-switch` `display: none`)：已隐藏
- [❌] **"未激活" + "—" 协议名**：未选协议时无意义

**判定**: 协议条在未连接/未选协议状态下**信息全冗余**，应该精简为：仅显示"● 当前协议" 状态指示 + 已选协议时显示协议名 + 已连接 + 已选协议时显示"设置值"按钮。

### 底部"设置值/字节预览"区（主区）
- [❌] **"设置值" 标题**：未连接时无字段可设
- [❌] **"字节预览 (buildFrame)" 标题**：未连接时无帧可预览
- [❌] **空 `—` 占位区域**：永远不更新，**纯粹视觉噪音**

**判定**: 整个底部区在未连接 / 未选协议时**应该 display: none**。v1.2.1 changelog 写"挪到 modal"但**实际 HTML 还有常驻区**（v1.2.1 改造未完成）。

## 修复方案

### 方案 A（推荐）：精简协议条 + 隐藏底部空区

**协议条**（未连接状态）:
```
[● 未激活]                                                      
```

**协议条**（已连接 + 已选协议）:
```
[● 已激活] [BMS Test Protocol]                       [⚙ 设置值]
```

**底部"设置值/字节预览"区**：
- 整个 div 包裹一个外层 `id="dh-dash-settings-region"`
- 默认 `display: none`
- `!NS.serialConnected || !NS.activeProtoId` 时**永远隐藏**
- 已连接 + 已选协议时**仍然不显示在主区**——只在用户点"⚙ 设置值"按钮时弹 modal

### 方案 B：彻底删底部常驻区代码

直接删掉主区的"设置值" + "字节预览" HTML 块（v1.2.1 changelog 写的"挪到 modal"应该是方案 B 的意图，但没执行完）。

### 我推荐方案 A + B 结合

1. 方案 B 删底部常驻区（v1.2.1 changelog 写"挪到 modal"本来就该这么做）
2. 方案 A 精简协议条（去掉冗余信息）
