⑦ 告警编辑 Modal 新增 问题 3 (告警编辑)

告警编辑是 v1.2 新增的独立 modal，替代之前"从卡片派生"模式。支持多种触发条件 + 严重度 + 通知方式。

编辑告警规则
同规则重复触发最小间隔, 默认 2000ms
联动提示：此规则引用 BMS · 0x01 · cell_1_v。删除/重命名该命令或字段会断开引用, 需手动修复。
ID: alert_3 · 创建于 2026-08-10
实现要点：新增 NS.openAlertEdit(alertId?) 函数。新建模式：自动生成 alert ID。编辑模式：填入现有值。保存时校验 cmd/field 引用是否还存在（防止 orphan alert）。
设计原则（与你之前提的偏好一致）：
① 数据字段归命令不归协议 — 字段不污染协议配置，跟用户原本的"命令自带 dataFields"逻辑一致
② 添加用 modal 不用内嵌表单 — 命令/卡片/告警都走弹窗，列表只展示
③ 图标 inline SVG Lucide 16x16 stroke 1.5 — 全程不引外部图标库
④ 正交分层一站式 modal — 配置中心 5 tab + 3 个编辑 modal，每页目标单一
⑤ 工具栏按钮越少越好 — 每个 tab 工具栏最多 3 个，行操作在表格内
