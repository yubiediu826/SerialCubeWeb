# v1.3.13 — 卡片布局收尾 + set 卡数据源/自动/手动发送

**发布日期**: 2026-08-17
**关联 spec**: 无 (基于用户实拍截图反馈的 hotfix)
**关联 mockup**: 无 (基于 v1.3.12 已有 mockup, 在实装上小幅调整)

## 用户反馈 (2026-08-17)

> 1. 控制卡和参数卡文本应该置于底部模仿趋势卡
> 2. 趋势卡箭头所指的横线移除
> 3. 参数卡缺失数据源模式比如 fixed/random/sine/ramp 和控制自动发送和手动发送

## 改动详情

### 1. control/set 卡 footer 文本推到底部 (line 6217-6219)

**问题**: control/set 卡 card-body 是 `display:flex; flex-direction:column`, 但只有 trend/pair 卡有 `.card-trend { flex:1 }` 撑开空间。control/set 卡没有这层, 导致 `.card-footer` 浮在卡中段, 底部留 50+px 空白。

**修复**:
```css
.dashboard-host .card-default.control .card-footer,
.dashboard-host .card-default.set     .card-footer { margin-top: auto; }
```

**效果**: 跟趋势卡 `.card-trend { flex: 1 }` 等效 — 推 footer 到卡底, 4 类卡底部布局一致。

### 2. trend 卡范围指示条 (range-bar) 移除 (line 17649, 17676 + CSS line 6081)

**问题**: trend 卡 value 区有 4px 灰色横条 + 2px 蓝色 marker, 表示当前值在范围内的相对位置。用户反馈"横线视觉干扰", 且范围信息已在 footer 文字 ("范围 0-100%")。

**修复**:
- renderCard (line 17765): 注释改为"v1.3.13: 范围指示条 marker 移除", 删除 `barPct/barCls` 计算 + `<div class="range-bar">` 元素
- CSS (line 6081): `.range-bar`/`.marker`/`.threshold` 3 段样式整段删除 (注释一行说明)
- eval 验证 `hasRangeBar: false`

### 3. set 卡数据源下拉 + 自动/手动发送 (line 6176-6199 CSS, 17657+ renderCard, 17440-17483 新函数)

**问题**: set 卡 footer "数据源 fixed" 是死文本, 没法在卡上改数据源模式; 也没法在卡上触发发送。

**修复**:
- **数据源下拉** (`<select class="set-src-select">`): 4 选项 fixed/random/sine/ramp, 改 → 重算 `c.sim = NS._simSourceParam(newType, value)` + 持久化
- **自动 toggle** (`<label class="set-auto-toggle">` + checkbox): 勾 → 启动 setInterval 每 1000ms 自动发送; 取消 → 停 ticker; 持久化 `c.autoSend`
- **手动按钮** (`<button class="set-send-btn" data-action="send-set">`): 单击 → `NS._sendSetFrame(c)` (类似 control 卡的 `_sendControlFrame`, 用 `_simTick` 算本拍值后组帧发送)
- **新函数**:
  - `NS._sendSetFrame(c)` — 手动发送, line 17440
  - `NS._setAutoSendTick(c)` — 自动 ticker 调度, line 17459
  - `NS._simTick(c)` — 按 c.sim 规则算一帧值 (fixed=常量, random=lo~hi, sine=base+amp*sin, ramp=cur+step 循环), line 17468
- **NS.start() 恢复 ticker** (line 18890): 页面重载后自动重启用户已勾 autoSend 的卡

**4 行变 5 行**: 控制卡 / 趋势卡不变; set 卡从 (header/参数值/当前/footer) 4 行变 (header/参数值/当前/数据源/发送/footer) 6 行, 单卡高度仍 198px 容纳。
