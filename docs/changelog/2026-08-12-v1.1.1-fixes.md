## 🎯 4 个修复点

### 修复 1: 主题切换入口 → 主系统菜单 segmented

- **位置:** topbar 右上角 3 横线菜单 (主 `system-menu`),在"关于"和"配置"之间
- **新增 HTML:** `.theme-seg#sys-theme-seg` 含 3 按钮 (浅色/深色/跟随) + Lucide inline SVG 图标
- **新增 CSS:** `.floating-menu .theme-seg` 样式块 (2px 圆角 + active 态白色 box-shadow)
- **新增 JS:** `bindSystemMenuThemeSeg()` IIFE — 初始化 active 态 + click → 复用已有 `handleThemeChange()`
- **业务逻辑:** 0 行新增,完全复用 v1.0.0 已有的 `state.theme` / `applyTheme()` / `handleThemeChange()`
- **清理死按钮:** 删除仪表盘内部 `dh-menu-theme` 死按钮 (行 7508, 带 TODO 注释)

### 修复 2: "配置中心" → "协议配置" 改名

- **位置:** `dh-config-center-modal` 行 7726 (modal title) + 工具栏行 7514
- **修改:**
  - modal 标题 `配置中心` → **`协议配置`** (用户指定)
  - 副标题简化 `协议 / 命令 / 卡片 / 告警 / 导入导出` → `协议 / 命令 / 字段 / 导入导出`
  - modal header 右侧 `开始引导` 按钮 → **`新建协议`** (data-svg 改 plus,click handler 改 `openNewProtocolWizard`)
  - 工具栏 `配置中心` → `协议配置` (同一 button id, 文字态)
- **保留:** modal id `dh-config-center` 不变 (改 id 影响 ~30 处 JS 引用)

### 修复 3: 编辑模式视觉强化 + 卡片角标

**3a. 编辑模式按钮 active 态**
- **位置:** `.dashboard-host .toolbar-btn.active` (行 5700)
- **修复:** CSS 加 `!important` 锁住 (被 :hover 覆盖) + 绿点 ::before 装饰
- **文字态切换:** 给 span 加 `id="dh-toggle-edit-label"`,JS toggle 时 `编辑模式` ↔ `编辑中`

**3b. 卡片右上角 action 按钮**
- **位置:** `.dashboard-host .card-default .card-action` (行 6065-6081)
- **修复:**
  - 尺寸 16px → **20px**
  - `transparent` 背景 → `var(--bg-panel)` 浅底
  - 加 `1px solid var(--border)` 边
  - hover 强化:`accent` 边 + `accent-soft` 浅蓝底 (edit) / `danger` 边 + 浅红底 (del)
- **JS 配合:** appendChild 的 delete button `className` 从 `'card-delete-btn'` 改为 `'card-action del'`,复用同一套样式

### 修复 4: Modal Stack 嵌套 (核心)

- **位置:** `NS.openModal` / `NS.closeModal` 重构 (行 12520-12565) + 协议配置 4 处 `NS.closeModal('dh-config-center')` 删除
- **重构方案:**
  - 新增 `NS._modalStack = []` 全局栈
  - `openModal` push + 动态 z-index `1000 + stack.length * 20`
  - `closeModal` 弹栈 + 保持原有 `cssText = ''` 清理 inline style
  - 协议配置 4 处 `closeModal('dh-config-center')` 删除 (行 12824/12863/12934/13612)
- **Esc 键:** `document.addEventListener('keydown', ...)` 一次性绑定,只关栈顶 modal
- **用户体验:**
  - 协议配置 → 点新建协议 → 新建协议 wizard 叠加在协议配置上 (z 高)
  - 关闭 wizard → 自动回到协议配置 (z 降回栈底)
  - Esc 键逐层关闭,不一次关到底
