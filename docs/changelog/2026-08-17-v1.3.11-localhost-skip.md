# v1.3.11 — trackSerialWebView 跳过本地环境

**VERSION**: 1.3.10 → 1.3.11
**日期**: 2026-08-17
**类型**: hotfix (控制台噪音清理)

## 背景

`/api/serialweb_page-view` 是部署在 Cloudflare Worker + KV 的浏览量统计接口, 仅在 `yubiediu826.github.io/SerialCubeWeb/` 域名下可用。

应用层在 `trackSerialWebView()` 里有 `if (window.location.protocol === 'file:') return;` 防御, 但没防 `localhost` / `127.0.0.1` —— 本地用 `python -m http.server` 启动或 L3 e2e 跑测试时, fetch 必然 404, 浏览器原生 console 必出 1 条 `Failed to load resource: 404`, 污染控制台 (功能上 .catch(()=>{}) 已吞, 无功能影响)。

## 修复

`SerialCube.html` line ~23741, `trackSerialWebView` 加 hostname 守卫:

```js
const h = window.location.hostname;
if (h === 'localhost' || h === '127.0.0.1' || h === '0.0.0.0' || h === '::1') return;
```

- `node tests/e2e/smoke.spec.mjs`: 10/10 PASS, 1.93s 稳定
- console.error 计数: 0 (之前 1, 现在 0)
- 4xx 资源计数: 0 (之前 1, 现在 0)
- 生产环境 `yubiediu826.github.io/SerialCubeWeb/`: hostname 是 `yubiediu826.github.io`, 不在跳过名单 → 浏览量统计照常工作
