# v1.3.8 — 主机/从机模式切换 + 默认协议 host/slave + 参数卡 + 字段视图修复

**VERSION**: 1.3.7 → 1.3.8
**日期**: 2026-08-16
**类型**: feature + 架构重构 + bug fix

## 背景

用户反馈 4 个核心问题仍未解决：

1. 应在「协议配置」按钮旁加一个**模式切换按钮**（主机/从机），移除「仿真」按钮。
2. 需要新卡片类型：主机模式显示 0x01 控制位表卡 + 0x01 从机响应卡；从机模式需要可直接设置参数值 + 动态调整、且**无图表**的参数卡。
3. 移除默认协议，添加 `bms_v113_host` + `bms_v113_slave` 为默认协议。
4. 从机 0x01 应有 48 字段（部分按位解析），当前协议字段为 0；主机/从机都要有对应卡片。

## 修复

### P1 — 工具栏模式切换按钮

- 删除「仿真」按钮，新增 `#dh-mode-seg` 分段按钮（主机/从机）。
- 新增 `NS.setSimMode(mode)`：切 `_simRole` + 同步 `activeProtoId`（host→`proto_bms_v113_host` / device→`proto_bms_v113_slave`）+ 轮询启停 + 持久化 + 重渲染 + 按钮高亮。
- 角色唯一入口 = 工具栏按钮；旧 sim modal 角色段废弃（保留数据源高级配置）。

### P2 — 默认协议 host/slave

- `_defaultProtocols()` 返回空数组（移除 legacy BMS/Modbus/合并版/EMS）。
- `_registerSchemaProtocols()` 注册 `proto_bms_v113_host`（role host）+ `proto_bms_v113_slave`（role device），各持完整双向 schema 的深拷贝 + 19 命令。
- `reset()` 重新注册 schema 协议 + 生成默认卡片 + 默认 host 模式。

### P3 — 角色感知卡片类型

- 新增 `NS._cardVisibleInRole(c)`：control 仅 host；set 仅 device；trend 两种都显示；pair 仅 host。`renderCardGrid` 按此过滤。
- 新增 `type:'set'`（从机参数卡）：参数值输入框（即时更新 `card.sim`）+ 数据源类型 badge + 当前值回显，**无图表、无 sparkline**。bitset 字段（ProtectCode 等）显示 hex 值。
- `_generateSchemaCards(role)` 按角色生成：host → 0x01 控制卡 + 6 张遥测 trend 卡；device → 12 张关键字段 set 卡 + 4 张保护标志位 bitset set 卡。
- 卡片编辑 modal 新增「参数卡 (从机, 无图表)」类型 + 从机数据源段（固定/随机/正弦/斜坡）。

### P4 — 协议字段视图修复（字段不再为 0）

- 命令 tab `_configCenterTabRenderers.commands`：schema 协议时字段从 `schema.commands[cmd].CB/MB.fields` 读（含 bitset 位展开、数组 `[count]`），显示「N 字段: ...」，不再读恒空的 `cmd.dataFields`。
- 0x01 从机 = 48 CB 字段 + 7 个 bitset 字段逐位展开；0x01 主机 = 1 个 ctrl bitset（16 位）。
