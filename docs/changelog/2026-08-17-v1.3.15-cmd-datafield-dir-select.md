# v1.3.15 — 编辑命令 modal 数据字段方向列改为下拉 (hotfix)

**发布日期**: 2026-08-17
**关联 spec**: 无
**关联 mockup**: 无

## 用户反馈 (2026-08-17)

> 编辑命令这里有 TX 和 RX, 但是没法设置发送方向

## 根因

`SerialCube.html` line 22988 (v1.2 时代遗留) 数据字段"方向"列是只读 `<span>`:

```javascript
'<td><span class="df-dir ' + (df.dir || '') + '">' + (df.dir === 'tx' ? 'TX' : df.dir === 'rx' ? 'RX' : '—') + '</span></td>'
```

方向来源: `_renderNewCmdDataFields` line 21387/21391 从 `txFields` / `rxFields` 派生 `dir: 'tx' | 'rx'`, 写入 dataFields.dir 一次就完事, UI 不能改。

整体命令方向 (顶部 "方向" select) 是可改的, 但**单字段方向**改不了 — 用户实测想从 MB 段把 ctrl 字段移到 CB 段做不到。

## 改动详情

### 1. 方向列只读 span → 下拉 (line 22987-23006)

```javascript
const dirSelect = (df, i) => '<select class="new-cmd-df-dir" data-df-dir="' + i + '">'
  + '<option value="tx"' + (df.dir === 'tx' ? ' selected' : '') + '>TX 发送</option>'
  + '<option value="rx"' + (df.dir === 'rx' ? ' selected' : '') + '>RX 接收</option>'
  + '<option value="both"' + (df.dir === 'both' ? ' selected' : '') + '>TX+RX</option>'
  + '<option value=""' + (!df.dir ? ' selected' : '') + '>— 无</option>'
  + '</select>';

list.innerHTML = '<table class="wiz-field-table"><thead>...<th>方向</th>...'
  + s.dataFields.map((df, i) => '<tr data-df-index="' + i + '">'
    + '<td>' + dirSelect(df, i) + '</td>'
    + ...
```

4 选项: TX 发送 (MB) / RX 接收 (CB) / TX+RX (双向) / — 无 (不参与帧编码)。

### 2. updateState 同步 (line 23039-23048)

```javascript
const updateState = () => {
  document.querySelectorAll('#dh-new-cmd-dataFields-list tr').forEach((tr) => {
    ...
    // v1.3.15: 方向 select 同步 (旧版只读 span, 用户改不了)
    const dirEl = tr.querySelector('.new-cmd-df-dir');
    if (dirEl) df.dir = dirEl.value || undefined;
    ...
```

### 3. select 已有 input/change 监听 (line 23065-23068)

```javascript
document.querySelectorAll('#dh-new-cmd-dataFields-list input:not(.bit-name), #dh-new-cmd-dataFields-list select').forEach((el) => {
  el.addEventListener('input', updateState);
  el.addEventListener('change', updateState);
});
```

new-cmd-df-dir 是 select, 已经被这条 batch 监听器覆盖, 不需要额外绑定。

## 已知限制 (v1.3.15 不修)

**Schema 命令 (如 0x01)**: 用户的 dataFields 是从 `txFields/rxFields` 派生的, 保存时 `_saveNewCommand` (line 23245) 会**保留原 txFields/rxFields 不变**:

```javascript
if (s._originalCmd && (s._originalCmd.txFields || s._originalCmd.rxFields)) {
  newCmd.txFields = s._originalCmd.txFields;  // 保留原
  newCmd.rxFields = s._originalCmd.rxFields;  // 保留原
  ...
}
```

意味着用户在 modal 里改字段方向, 保存后 txFields/rxFields 没变 — 重新打开 modal 还是看到原方向。

要真改, 需要:
1. 保存时按 dataField.dir 重切 txFields (dir in ['tx', 'both']) / rxFields (dir in ['rx', 'both'])
2. 字段重排后 MB.len / CB.len 重算 (txLen/rxLen)
3. 帧预览随字段顺序变化

这超出 hotfix 范围, 留 v1.3.16+ 重构时一并处理。

**非 schema 命令 (raw/fixed-header kind)**: 可正常保存, 改方向后 dataFields.dir 正确, _saveNewCommand 把 dataFields 写入 newCmd.dataFields (line 23241-23243), 下次打开 modal 看到新方向。
