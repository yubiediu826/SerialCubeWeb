## 风险点 / 经验教训

- **bit-history 弹窗里 .detail-page-tabs 静态 HTML 仍显示「图表/日志」2 tab**，但 chartPageEl=no（chart 页未渲染）。理想是按 card.type 动态渲染 tabs。影响小（用户不点图表 tab 即无副作用），留 v1.3.21 顺手修
- **handoff 行号偏移**：handoff 写 18050，实际 18050 是 rx 分支取数代码，bit_set 分支 fallback 在 18004。子 agent 通过 grep 自行定位后修正
- **bump-version 脚本 minor 会跳版本**：当前是 1.3.19（不是 1.3.19.1），用 minor 会跳到 1.4.0。改用 patch (1.3.19 → 1.3.20) 正确
