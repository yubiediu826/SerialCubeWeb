## v1.3.1 · 2026-08-13

**主题:** 三选项级联 modal · 协议/命令/卡片删除 · 引用预览 chip

### 改动点

1. **三选项级联 modal** — 协议/命令/卡片删除时弹自定义 modal (替换 v1.2 browser confirm)
2. **3 选项按钮** — [取消] (ghost) / [仅删自己] (default) / [级联删除 (N 个)] (primary danger)
3. **引用预览 chip** — 彩色分类显示被引用的命令/卡片/告警 (蓝紫/绿/红)
4. **"仅删自己" hint** — 自动算孤儿数, 提示会留 N 个孤儿
5. **主题适配** — 浅色 + 深色, 跟其他 modal 设计语言统一
6. **保留兼容** — 旧 NS._cascadeConfirm 保留 (不删不调用), 告警删除简单 confirm 不变
7. **3 个 e2e 场景** — 19-cascade-protocol-delete / 20-cascade-command-delete / 21-cascade-card-delete
