### 1. 颜色变量体系: 浅深双套, 5 个新 type 各自独立 token

```css

  --log: #92400e;       --log-soft: rgba(146, 64, 14, 0.14);     /* 棕 — LOG 卡片 (历史日志) */
  --wizard: #0891b2;    --wizard-soft: rgba(8, 145, 178, 0.14);  /* 青 — WIZARD 卡片 (设置向导流程) */
}
.theme-dark {
  --big: #22c55e;       --big-soft: rgba(34, 197, 94, 0.16);
  --array: #a78bfa;     --array-soft: rgba(167, 139, 250, 0.14);
  --string: #98989f;    --string-soft: rgba(152, 152, 159, 0.16);
  --log: #f59e0b;       --log-soft: rgba(245, 158, 11, 0.16);
  --wizard: #22d3ee;    --wizard-soft: rgba(34, 211, 238, 0.16);

```

- **5 个 token 对应 Task 7-10 的 5 个新卡片类型** — Task 7-10 worker 直接用 `--big-soft` 给 BIG 卡片背景, `--array` 给 ARRAY 边框等
- **暗色主题用更亮色阶** (绿 #16a34a → #22c55e, 蓝紫 #5b21b6 → #a78bfa) — 配合暗背景提升对比度
- **-soft 透明度** 浅色 12-14% / 暗色 14-16% — 暗色背景纯度低, 软色块需要稍高不透明度

### 2. 尺寸体系: 1×1 默认 + 2×1 横向 2 倍, 通过 .span-2x1 class 触发

```css
.card-default.span-2x1 { width: 440px; }
.card-default.span-2x1 .card-body { padding: 10px 14px 8px; }
.card-default.span-2x1 .card-title { font-size: 0.8125rem; }  /* 0.6875 → 0.8125, 双倍空间大标题 */
.card-default.span-2x1 .card-value .num { font-size: 1.75rem; } /* 2 → 1.75, 不要喧宾夺主, 让 sparkline 也有空间 */
.card-default.span-2x1 .card-footer { font-size: 0.625rem; }
```

- **不用 grid span 而用 width** — SerialCube 的 `.card-grid-area` 走 flex (line 5914 `display: flex; flex-wrap: wrap;`), 显式 width 440px 最简单
- **2×1 卡片 body padding 加大** (10/14 vs 4/10) — 双倍空间给内部元素更多呼吸感
- **num 字号反而减小** (2rem → 1.75rem) — 2×1 卡片有 sparkline 占右侧, 数字不能跟 1×1 一样大, 否则视觉不均衡

### 6. _switchDetailPage 扩展 'big'/'text' page

```javascript
NS._switchDetailPage = function (page) {
  if (page !== 'chart' && page !== 'logs' && page !== 'editor' && page !== 'big' && page !== 'text') return;
  // 'big'/'text' 仍对应 "图表" tab active (BIG/STRING 主内容在 chart slot)
  const activeTab = (page === 'big' || page === 'text') ? 'chart' : page;
  document.querySelectorAll('.detail-page-tab').forEach((b) => b.classList.toggle('active', b.dataset.page === activeTab));
  // 'big'/'text' 不用 'chart' 避免 chart tools (缩放按钮) 显示
  const tabs = document.querySelector('.detail-page-tabs');
  if (tabs) tabs.setAttribute('data-page', page);
  // 显隐 body 子页 — 'big'/'text' 复用 chart page slot
  body.querySelectorAll('.detail-page-chart').forEach((el) => el.style.display = (page === 'chart' || page === 'big' || page === 'text') ? 'flex' : 'none');
  body.querySelectorAll('.detail-page-logs').forEach((el) => el.style.display = (page === 'logs' || page === 'editor') ? 'flex' : 'none');
};
```

- **3 个新 page 值** — 'big' / 'text' / 兼容旧 'chart'/'logs'/'editor'

```javascript
// HEX 4 字节一行, 每行带 offset 标签 (0x00, 0x04, 0x08, 0x0C)
for (let i = 0; i < bytes.length; i += 4) {
  const slice = bytes.slice(i, i + 4);
  const lineHex = slice.map((b) => ('00' + (b & 0xFF).toString(16).toUpperCase()).slice(-2)).join(' ');
  const offset = ('0x' + i.toString(16).toUpperCase().padStart(2, '0'));
  hexLines.push(offset + '  ' + lineHex);
}
// ASCII 列: 可打印字符显示, 不可打印替换 .
const asciiRepr = bytes.map((b) => (b >= 0x20 && b <= 0x7E) ? String.fromCharCode(b) : '.').join('');
```

- **3 段信息** — ASCII 大字 (1.5rem monospace) + HEX 字节流 (4 字节一行带 offset) + ASCII 列 (可打印字符)
- **4 字节一行** — 紧凑 (16 字节 = 4 行) 又不挤 (每行 4 字节 + 2 字符 offset)
- **HEX & 0xFF 掩码** — `b & 0xFF` 防止有符号数 (如 -1 = 0xFF) 转 HEX 出错
