# v1.3.17 — 连接串口后未自动重渲染仪表盘卡片 (2026-08-17)

## 概述

修复仪表盘卡片区在 "协议已应用 + 串口未连" 状态下, 用户连接串口后卡片不显示的 bug。根因是 `updateSerialStatus()` 串口状态变化时只调 `updateDashboardProtoBar()`, 没同步重渲染 `renderCommandPanel / renderCardGrid / renderAlerts`。`renderCardGrid` 在 `_serialConnected=false` 时 return early 且清空 `innerHTML`, 所以占位区消失但卡片区是空的, 用户必须手动重新应用协议才能看到卡片。修复后跟 `toggleActiveProtocol` 对齐: 同步渲染 + rAF 防御性二次渲染。

## 改动

### 修复: updateSerialStatus 同步重渲染仪表盘

**v1.3.16 行为** (bug):

```javascript
if (prev !== state.serial.connected && typeof dashNS.updateDashboardProtoBar === 'function') {
  dashNS.updateDashboardProtoBar();
}
```

只调 `updateDashboardProtoBar()`, 切 `dh-dash-empty` / `dh-card-grid` 的 `style.display`。但 `renderCardGrid` (line 18016-18030) 在 `_serialConnected=false` 时:

```javascript
if (!NS._serialConnected) {
  el.style.display = 'none';
  return;  // <-- innerHTML 从未被填充
}
```

直接 return 没填充 `innerHTML`。所以连上串口后:
- `updateDashboardProtoBar` 设 `cardGrid.style.display = ''` (visible)
- `cardGrid` 容器是空的
- 用户看到 "占位区消失 + 卡片区是空白"
- 唯一恢复: 手动重新应用协议触发 `toggleActiveProtocol` 里的 rAF 二次渲染

**v1.3.17 修复**:

```javascript
if (prev !== state.serial.connected) {
  if (typeof dashNS.updateDashboardProtoBar === 'function') dashNS.updateDashboardProtoBar();
  if (typeof dashNS.renderCommandPanel === 'function') dashNS.renderCommandPanel();
  if (typeof dashNS.renderCardGrid === 'function') dashNS.renderCardGrid();
  if (typeof dashNS.renderAlerts === 'function') dashNS.renderAlerts();
  // 防御性 rAF 二次渲染 (跟 toggleActiveProtocol 保持一致)
  requestAnimationFrame(() => {
    if (typeof dashNS.updateDashboardProtoBar === 'function') dashNS.updateDashboardProtoBar();
    if (typeof dashNS.renderCommandPanel === 'function') dashNS.renderCommandPanel();
    if (typeof dashNS.renderCardGrid === 'function') dashNS.renderCardGrid();
  });
}
```

跟 `toggleActiveProtocol` (line 21607-21611) 完全对齐, 行为一致性 + rAF 兜底任何动画/遮罩吞首次渲染。

## 触发场景

1. 用户在配置中心 "应用" 某协议 → `activeProtoId` 设置, 但串口未连
2. 占位区显示 "disconnected-with-proto" 文案, 卡片区 `display:none` 且 `innerHTML` 为空
3. 用户连接串口 → `state.serial.connected = true`
4. `updateSerialStatus` 触发 → `_serialConnected = true` + 4 个 render 调用
5. `renderCardGrid` 看到 `_serialConnected=true` + `activeProtoId` 都有, 正常填充卡片 → 用户立刻看到卡片
