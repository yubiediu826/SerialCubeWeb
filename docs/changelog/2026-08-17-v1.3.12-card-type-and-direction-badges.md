## 改动概览

3 块 UI 改动, 全部基于真实 SerialCube 现有 CSS token, 卡片尺寸不变 (220×198px).

### 1. 卡片右上角 type 缩写 badge (新)

| 类型 | 缩写 | 颜色 | 卡片 |
|------|------|------|------|
| 控制位 | `CTRL` | 橙 (#d97706) | 10 张 control |
| 参数 | `SET` | 蓝 (#3a5ccc) | 12 张 set |
| 趋势 | `TREND` | 蓝 (跟随 alert 变橙/红) | 6 张 trend |
| 配对 | `PAIR` | 紫 (#8b5cf6) | charge_v_pair |

实现: 新增 `.type-badge` + 4 个 modifier (`.ctrl`/`.set`/`.trend`/`.pair`), 复用 `.card-status-badge` 风格 (line 6046-6054).

### 2. 命令方向 badge (新, footer 右下角)

| 方向 | 显示 | 颜色 | 卡片 |
|------|------|------|------|
| TX | `● TX` | 蓝 | 10 张 control |
| RX | `● RX` | 绿 | 6 张 trend |
| TX+RX | `● TX+RX` | 紫 | 12 张 set (双向) |
| RX + 告警 | `● RX · DANGER` | 红 | alert-danger 趋势卡 |

实现: 新增 `.footer-direction` + 3 个 modifier (`.tx`/`.rx`/`.both`), 复用 `.footer-status` 风格 (line 6211-6221).

### 3. control 卡 ON/OFF 状态突出

- **大字 (2rem)**: 单 bit 状态 `ON` (绿 #22c55e) / `OFF` (黑)
- **小字 (0.5625rem, value 区内右下角)**: 字段值 `0xXXXX` + 位编号 `bit N`
- **按钮合并**: `ctrl-row` 一行 2 按钮 (toggle + send), 移除原 `ctrl-single-row`
- 跟实际 SerialCube 单 bit 控制卡对齐, 跟真机协议栈调试习惯一致 (状态最重要, 字段值辅助)

### 4. bug 修复: list type 标签

`renderCardEditList` (line 20336) 硬编码 `'TREND'`, 修复为 4 元:
```js
<span class="ce-type">${c.type === 'pair' ? 'PAIR' : c.type === 'ctrl' ? 'CTRL' : c.type === 'set' ? 'SET' : 'TREND'}</span>
```

## 跟真实 SerialCube 对齐

- 颜色 token: 全部用现有 `--ctrl` / `--signal` / `--ok` / `--warn` / `--bad` / `--both` 变量
- 字体 token: 全部用现有 `--font-mono` (Cascadia Code) / `--font-ui`
- 字号: 2rem (value num) / 0.5625rem (badge) / 0.6875rem (title) 跟 line 6000-6240 一致
- 圆角/阴影/边框: 跟 `.card-default` 基础类一致

## 兼容性

- `c.dir` 字段保留解析 (旧 config 兼容), 不再用于新逻辑
- 多 bit 模式 (ctrl-bits) 保留 (line 6126-6138)
- pair 卡 type badge 暂未实施 (本次没改 pair 卡), 后续可补
