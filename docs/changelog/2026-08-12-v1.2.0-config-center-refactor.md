# v1.2.0 · 2026-08-12 · 配置中心重构

## 主题

**单协议聚焦 + 串口绑定 + 告警独立 + 命令三模式**

一次性解决用户反馈的 5 个配置中心 UI/逻辑自洽性问题。

## User-facing 改动

### 1. 仪表盘重做 (单协议聚焦)

- **未连接时：** 显示"未连接串口"占位 + DB9 串口图标 + "选择串口"按钮
- **已连接时：** 顶部"协议条"显示当前协议 pill + 协议名 + 串口信息 + "切换协议"按钮
- 仪表盘只渲染 `card.protocol === NS.activeProtoId` 的卡片
- 卡片 UI 沿用 v1.1.1 (用户偏好)，仅移除协议徽章
- 告警触发时卡片右下角红点 + 1.5s 高亮

### 2. 配置中心 4 tab 重做

- **Tab 1 协议：** 列表 + 状态徽章 ("● 使用中" / "未使用") + 编辑/复制/删除
- **Tab 2 命令：** 表格 + 编辑/复制/删除 (原只有删除)
- **Tab 3 卡片：** 加"协议"列 (pill 颜色区分) + 新建引导 (先选协议+命令)
- **Tab 4 告警：** 独立规则列表 + 严重度筛选 (info/warn/danger) + 编辑/删除

### 3. 命令编辑 modal 增强

- **三模式复用：** `openNewCommandModal(protocolId, editCmd?)`
  - null = 新建，传 cmd = 编辑，浅拷贝 + 新 ID = 复制
- **帧预览 (新增)：** hex 风格显示 (沿用 SerialCube.html 现有 2 字节大写 + 空格分隔格式)
  - 背景 `var(--bg-terminal)` 自动适配浅/深色
  - 字段类型色块区分 (u8/u16/s16/float/CRC)
  - 字段值变化即时重算 + CRC 重算
- **批量默认值 (新增)：** 弹 prompt 一次性设置所有字段默认值

### 4. 告警独立规则

- 新增 `NS.ALERTS` 数组，从卡片 range 派生改为独立存储
- 严重度支持 info / warn / danger 三档
- 通知方式支持 toast / sound (v1.3) / list
- 防抖时间可配 (默认 2000ms)
- "从卡片重建"按钮：扫所有 card.range 自动生成默认 warn 规则
- 告警编辑 modal (`openAlertEdit`) 支持新建/编辑/另存为副本

### 5. 删除级联 confirm

- 删除协议/命令/卡片时弹 confirm 列出引用方
- 引用数量为 0 时不弹 (直接删)
- 有引用时用户选 [确定] = 级联 / [取消] = 不删
- 通用函数 `NS._findReferences` + `NS._cascadeConfirm`

### 6. 调试面板占位 (v1.3 真实模拟)

- 仪表盘右下角浮动 ⚙ 按钮 (默认折叠)
- 展开显示 2 个占位区块："主从连接 (BroadcastChannel)" + "数据注入 (Mutator)"
- v1.2 是灰字 "v1.3 待实现"，v1.3 实装

## 主题适配 (新原则)

- v1.2 所有新 UI 用 CSS 变量 (`var(--bg-terminal)` / `var(--text)` / `var(--accent)` 等)
- 禁止硬编码颜色 (#0d1117 / #79c0ff 等)
- 自动跟随系统 `prefers-color-scheme` + 用户手动切换 (`theme-light` / `theme-dark` class)
- 帧预览等"终端"风格区块用 `var(--bg-terminal)` 自动切换

## 数据结构变化

### 新增字段

| 字段 | 实体 | 默认 | 用途 |
|------|------|------|------|
| `protocol` | `CARDS[i]` | `'proto_bms'` | 卡片归属协议 |
| `activeProtoId` | `NS` (全局) | `null` (未连接) | 当前激活协议 ID |

### 新增全局变量

| 变量 | 类型 | 初始值 | 用途 |
|------|------|--------|------|
| `NS.ALERTS` | Array | `[]` | 告警规则独立存储 |
| `NS.activeProtoId` | String\|null | `null` | 当前激活协议 |
| `NS._pendingConnectPort` | SerialPort | `null` | 串口连接中间态 |
| `NS._debugPanelCollapsed` | Boolean | `true` | 调试面板折叠 |

### v3 配置格式

```json
{
  "type": "SerialWebUserConfig",
  "version": 3,
  "userConfig": {
    "dashboard": {
      "protocols": [...],
      "cards": [...],
      "alerts": [...],
      "settings": {
        "cmdMismatchEnabled": true,
        "alertDebounceMs": 2000,
        "cardLayout": "...",
        "activeProtoId": "proto_bms"
      }
    }
  }
}
```

兼容 v1/v2 导入（自动迁移）。
