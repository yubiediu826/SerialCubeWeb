# v1.3.1.1 hotfix — Cascade Modal 位置 + inline display:none 修复

**日期**: 2026-08-13
**前序**: v1.3.1 三选项级联删除 modal (commit 81deb3e)
**触发**: 用户实测 v1.3.1 发现「协议 / 命令 / 卡片删除都没弹窗」

## 问题

v1.3.1 commit 81deb3e 的 `dh-cascade-delete-modal` 有 **2 个独立 bug**，共同导致 modal 永不显示：

### Bug 1: `style="display: none;"` inline 优先级锁死 modal
- v1.3.1 commit 在 modal HTML 元素上加了 `style="display: none;"`（line 8548 原版）
- `NS.openModal('dh-cascade-delete')` 只调 `classList.add('open')` 切到 `display: flex`
- inline `style` 优先级 > 外部 CSS 规则，**盖过** `.dashboard-host .modal.open { display: flex }`
- 结果：modal 永远 `display: none`

### Bug 2: modal 写在 `.dashboard-host` 闭合 div **之后**（外部）
- v1.3.1 commit 把 cascade modal 段插在 `</div></section></div>` (line 8540-8542) **之后**
- 但 line 8540 才是 `.dashboard-host` 真正的收尾（line 8541 `</section>` 和 line 8542 `</div>` 实际是 HTML 容错的孤立关闭）
- 结果：cascade modal 在 dashboard-host **外部**，不匹配 `.dashboard-host .modal { display: none }` 作用域
- 退化为 `display: block` (div 默认) + 继承不到 `position: fixed` → **inline 渲染在 page 末尾 y=798+**
- 验证：inspect 时 modal 按钮 layout box x:0/48/145（左侧），y:901（viewport 高度 782 之外）

## 修复

| 位置 | 改动 |
|---|---|
| `SerialCube.html` line 8548 | 删 inline `style="display: none;"` |
| `SerialCube.html` line 8540-8590 范围 | cascade modal 整段移到 `.dashboard-host` 内部（dashboard-host 收尾 line 8540 之前） |
| `SerialCube.html` line 8724 | VERSION `1.3.1` → `1.3.1.1` |

## 验证

- **修改前** inspect 列 66 个元素（含 cascade modal 默认显示的"取消 / 仅删自己 / 级联删除"按钮，layout box 非零）
- **修改后** inspect 列 58 个元素（cascade modal 按钮**消失**——证明默认 `display: none` 生效）
- fullPage 截图能看到 modal 在 page 末尾（Chromium fullPage 截图机制把 fixed 元素画在 page 末尾，**不**代表 fixed 失效）

## 经验

- **inline style 优先级**：HTML 元素加 inline `display: none` 后，**任何** JS 切 `classList` 都无法显示。**不**要再加 inline 样式防闪烁——用 `<style>` 默认 `display: none` + `.open` class 切显示
- **CSS 作用域**：所有 modal **必须** 写在 `.dashboard-host` **内部**，否则 `.dashboard-host .modal { ... }` 规则不匹配
- **HTML 容错**：原 line 8541 `</section>` 跟 line 8542 `</div>` 没有对应开标签——浏览器自动闭合，`divCount` 跟踪会失真。**真正** dashboard-host 收尾是 line 8540 那个 `</div>`
- **HTML 验证**：v1.3 modal 真实收尾位置要数 v1.2 modal 整段 div 开闭配对，**不**是看代码缩进
