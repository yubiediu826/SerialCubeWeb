### 背景

v1.3.2 修完 3 个阻断 bug 后, 用户实测发现 3 个新问题:

1. **图 1**: 串口真连了 + 未应用协议, 仪表盘还显示"未连接串口"占位区 (串口状态没反映在文案)

### 已知问题 + 后续 (v1.3.3+ backlog)

- `_serialConnected` 由 `updateSerialStatus` 频繁同步, 在 agent-browser 等 mock 环境不易稳定测到 connected-no-proto 状态 (会被同步覆盖回 false), 但代码逻辑正确
- `connectSerial` 失败时如果之前已连, 状态可能不一致 (走 catch 分支但没显式 set connected=false)
- 切协议 rAF 防御是治标, 根本问题是 modal 动画期间 render 被吞, 应该用 MutationObserver 监听 modal close 事件再 render
