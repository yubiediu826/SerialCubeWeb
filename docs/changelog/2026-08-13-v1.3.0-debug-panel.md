## v1.3.0 · 2026-08-13

**主题:** 真实模拟调试面板 · BroadcastChannel 主从 · Mutator 数据注入

### 改动点

1. **调试面板实装 (v1.2.0 占位)** — 仪表盘右下角 ⚙ 折叠浮窗 (Lucide settings SVG, 去 emoji), 4 段布局 (Role/Channel/Mutator/Stats)
2. **BroadcastChannel 通信层** — 'serialcube-debug-v1' 同源, 1 人多 tab 模拟, 抽象 NS._debugTransport 接口 (BC MVP, 留 hook 升 WebRTC)
3. **Role 切换** (客户端 ↔ 设备端 segmented) — 切换时关闭现有 BC, 按新 role 重新初始化 + 广播 hello
4. **Channel 状态显示** — ● 已连接 (绿) / ● 未连接 (灰), 通道名 + peer 数
5. **Stats 实时计数** — tx / rx / err 3 列, debounce 100ms, 随收发自动更新
6. **Mutator 单条注入** — 选 field + 设值 + 注入, 客户端改 `NS.currentVals` (触发 checkAlert) / 设备端改 `NS._debugDeviceState` (下次 ack 用新值)
7. **预设场景 chip (4-6 个)** — 按 active protocol dataFields 自动推 (过压 / 欠压 / 通信超时 / CRC 错 / 边界值)
8. **通信超时 + CRC 错预设** — `NS._debugMutedUntil` + `NS._crcOverride` flag, 设备端 mute 期间丢弃 cmd 帧, CRC override 强制改 ack 帧末尾 2 字节
9. **3 个新 e2e 场景** — 10-debug-panel-role-switch / 11-debug-panel-mutator-inject / 12-debug-panel-multi-tab-sync
