# v1.3.14 — 卡片 tab 类型列漏判 control/set 修复 (hotfix)

**发布日期**: 2026-08-17
**关联 spec**: 无 (基于用户实拍反馈的 hotfix)
**关联 mockup**: 无

## 用户反馈 (2026-08-17)

> 卡片也全都是趋势卡?
> 协议配置中 0x01 命令的卡片类型不对, 我有 32 张卡但都是 TREND 趋势标签

## 根因

`SerialCube.html` line 21906 (`_configCenterTabRenderers.cards` typeStr 三元链) v1.3.10 旧版只判 pair:

```javascript
const typeStr = c.type === 'pair' ? '<span class="pill pcs">PAIR 对比</span>' : '<span class="pill info">TREND 趋势</span>';
```

control/set/trend 全掉到 TREND。`NS.CARDS` 实际数据正确 (10 control + 16 set + 6 trend = 32), 但**表格 UI 渲染** 跟实际数据脱节。

## 改动详情

### 1. typeStr 4 类都判 (line 21907)

```javascript
// v1.3.13 修: 4 类都判 (v1.3.10 旧版只判 pair, control/set 都掉到 TREND, 用户反馈卡片全显示"TREND 趋势")
const typeStr = c.type === 'pair' ? '<span class="pill pcs">PAIR 对比</span>' : c.type === 'control' ? '<span class="pill warn">CTRL 控制</span>' : c.type === 'set' ? '<span class="pill bms">SET 参数</span>' : '<span class="pill info">TREND 趋势</span>';
```

### 2. 顶部统计同步 4 类 (line 21938)

```javascript
// v1.3.13 修: 4 类计数 (旧版只数 TREND/PAIR, control/set 卡片看不见)
'<span ...>协议 X · 共 N 张卡片 (CTRL X / SET X / TREND X / PAIR X)</span>'
```

## 验证

agent-browser 实测 (BMS V1.13 协议默认 32 张卡):
```
{BMS_V113: 32, CTRL 控制: 10, TREND 趋势: 6, SET 参数: 16}
```

10 control + 16 set + 6 trend = 32 ✓ (与 `_generateSchemaCards` 生成逻辑一致)

## 关于"0x01 方向 TX+RX 双向"

`bms_v113.json` 协议本身没问题 — 0x01 是 1 条命令 (cmd id = 0x01) 同时有 MB (主机→BMS 控制) 和 CB (BMS→主机 遥测) 两段, 方向 'both' 是准确表达。卡片生成侧按 MB 字段拆 ctrl_bit0-9 (control, TX) + CB 字段抽 6 个 (trend, RX), 跟协议方向匹配。

如要把 0x01 拆成"0x01 发送"和"0x01 接收"两条独立命令, 需要改 `_schemaCommandList` 拆 MB/CB → 但会让协议层 (命令 ID 重复) 跟卡片层不一致, 不推荐。
